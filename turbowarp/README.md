# 用 TurboWarp 编写 TurboMC 脚本

TurboWarp 是本项目**唯一**的脚本编辑方式。游戏内只负责加载与运行，不提供积木拼接
（可以查看脚本树，但不能改）。

## 一、加载扩展

1. 打开 <https://turbowarp.org/editor>
2. 左下角「添加扩展」（积木面板底部的 ＋）
3. 滚到底部选「Custom Extension / 自定义扩展」
4. 选 **File** 标签，加载 `turbomc-extension.js`
   - 装了模组的话，游戏启动后会自动释放一份到 `.minecraft/config/turbomc/turbomc-extension.js`，
     直接用那个即可，不用再从仓库找
   - 仓库里 `turbowarp/turbomc-extension.js` 是同一份源文件；两者内容不一致时说明模组版本旧了
5. 积木面板出现紫色的 **TurboMC** 分类

> 也可以用 **Text** 标签把 js 内容粘贴进去，效果相同。
>
> `config/turbomc/` 下那份是模组每次启动按 jar 内版本覆盖的，改扩展请改仓库里的源文件。

## 二、扩展积木清单

### 事件

| 积木 | 说明 |
|---|---|
| 当受伤时 | 血量下降时触发 |
| 当玩家死亡 | 死亡边沿触发一次 |
| 当聊天包含 [MATCH] | 收到含关键词的聊天时触发；留空表示不过滤 |

### 输入

| 积木 | 说明 |
|---|---|
| 按键 [KEY] [按下/松开] | 按住或释放某个键。KEY 是下拉菜单，内置 Minecraft 全部 123 个键名（字母、数字、F1–F25、方向、修饰键、标点、鼠标三键、小键盘、功能键），直接选即可；要拼动态键名可拖入表达式 |
| 点击 [左/右/中] | 单次点击 |
| 按下鼠标 [左/右/中]? | 判断某个鼠标键是否**正被按住**（布尔）。读物理鼠标状态，打开背包/聊天界面时同样有效 |
| 点按 [KEY] 按住 [HOLD] tick | 按下并按住指定 tick 数后松开（阻塞）。KEY 同样是内置键名菜单 |
| 停止移动 | 释放所有移动键 |

### 移动与视角

| 积木 | 说明 |
|---|---|
| 走向 x:[X] y:[Y] z:[Z] | 用原版僵尸的 A\* 寻路走到目标坐标，遇到障碍会绕行。三个参数都是方块坐标，y 是目标**站立格**的高度。一次算不到目标时会先走近再接着算；总计约 60 秒走不到才放弃并松手。目标在水下时会下潜过去，氧气不足则中止并自动浮出水面 |
| 设置视角 水平:[YAW] 俯仰:[PITCH] | 直接设定视角角度 |
| 看向 x:[X] y:[Y] z:[Z] | 视角看向世界坐标（瞬时） |
| 平滑转到视角 水平:[YAW] 俯仰:[PITCH] | 用约 0.3 秒转到指定角度，**阻塞**到转到位。转头速度按剩余角度收敛，不是匀速 |
| 平滑看向 x:[X] y:[Y] z:[Z] | 同上，先算出目标方向再转。目标与眼睛重合时忽略 |

### 方块与挖掘

| 积木 | 说明 |
|---|---|
| 等待方块被挖破 | 阻塞直到准星方块消失（上限约 10 秒） |
| 正在挖掘 | 是否处于挖掘状态 |
| 挖掘进度 | 当前方块破坏进度 |

### 攻击：用左键点击，不提供专用积木

没有「攻击最近实体」这类积木，攻击靠输入积木完成：

```
点击 [左键]              ← 打准星指着的目标，走原版的射线与距离判定
按住 [mouse.left] 为「开」 ← 持续按住，由游戏自己按冷却出刀
```

**为什么不做攻击积木**：自己算「最近的实体」再发攻击包，很容易选到掉落物、经验球、
插在地上的箭——这几类在服务端会被判为「无效实体」并**直接断开连接**
（`multiplayer.disconnect.invalid_entity_attacked`），不是忽略。而且这类自动攻击
在带反作弊的服务器上还有转向突变、等间隔连点这些特征。

走左键点击则是原版管线：客户端自己做射线检测、自己判断目标与距离，服务端看到的
和玩家手点完全一样。

### 容器交互

| 积木 | 说明 |
|---|---|
| 打开坐标处的容器 x/y/z | 精确指定；超过 5 格会被服务端拒绝 |
| 界面槽位数 | 没有界面时返回 0——可用来判断「到底打开了没有」 |
| 槽位 [i] 的物品 | 返回注册名如 `minecraft:iron_ore`；空槽返回空串 |
| 槽位 [i] 的数量 | 空槽返回 0 |
| 第一个装着 [物品] 的槽位 | 找不到返回 -1；比脚本自己循环 36 格可靠 |
| 点击槽位 [i] 用 [左/右] | 拿起或放下；需要界面已经打开 |
| 快速移动槽位 [i] | 相当于 Shift+点击，容器与背包之间自动转移 |
| 关闭界面 | 恢复移动与操作 |

> 容器的槽位编号是固定的。以熔炉为例：`0` 输入、`1` 燃料、`2` 输出，
> 之后 27 格是玩家背包，最后 9 格是快捷栏。
>
> **点击是异步的**：发包后要等服务端回发槽位更新，同一帧内读到的仍是旧值。
> 每次点击后至少等 1 tick 再读状态，否则会写出「以为没动、重复搬十次」的脚本。
>
> 自动熔炼的一个可用写法：
>
> ```
> 打开坐标处的容器 (熔炉 x y z)
> 等待 0.3 秒                      ← 等界面真的打开
> 设 ore = 第一个装着 minecraft:iron_ore 的槽位
> 如果 非 (ore < 0) 则        ← 没有 ≥ 积木，用「非 (小于)」
>     快速移动槽位 (ore)           ← 直接进输入槽
> 设 coal = 第一个装着 minecraft:coal 的槽位
> 如果 非 (coal < 0) 则
>     快速移动槽位 (coal)
> 等待 10 秒                       ← 等烧炼
> 快速移动槽位 (2)                 ← 取出产物
> 关闭界面
> ```

### 交互与通讯

| 积木 | 说明 |
|---|---|
| 重生 | 请求重生 |
| 在聊天栏说 [TEXT] | 发送聊天消息 |
| 执行命令 [COMMAND] | 执行命令，自动补前导斜杠 |

### 查询 · 玩家

血量、饱食度、X/Y/Z 坐标、当前槽位、经验等级、手持物品、手持耐久百分比、背包已满?

### 查询 · 世界

是白天?、当前维度、在水中?、在岩浆中?、当前生物群系、脚下方块、坐标处方块、准星所指方块

### 查询 · 实体

最近实体距离 / X / Y / Z、最近敌对生物距离、最近实体名称、附近 [TYPE] 数量

### 运算与工具

背包中 [ITEM] 的数量、server ping (ms)、输出日志 [TEXT]

> 需要「大于等于」时用 `非 (A < B)`。Scratch 原生没有 `≥` 积木，这里不再重复实现一个——
> 判等、大于、小于都有原生积木，组合即可，多一个近义积木只会让人犹豫该用哪个。

## 三、可用的原生积木

**事件**：当绿旗被点击、当按下某键、当收到广播、当[计时器] > [N]
**控制**：如果、如果否则、重复、当…重复执行、对于…重复、永久循环、重复直到、等待、等待直到、停止
**侦测**：按下 [键]?、鼠标按下?（不分按钮，任一鼠标键按下即为真）、询问[问题]并等待、回答、用户名、计时器与当前时间
**运算**：比较、四则、取余、与或非、随机数、取整、拼接
**变量**：设定、读取、增加、显示/隐藏变量
**列表**：添加、删除、插入、替换、清空、取项、长度、包含、显示/隐藏列表
**外观**：说、思考（显示在 HUD 上）及其「N 秒」版本

> 「询问并等待」会弹出输入窗口：确定提交内容，ESC 或取消视为空回答——两者都会让脚本继续，
> 不会把脚本卡死。角色可见时问题同时显示在 HUD 气泡上。
>
> 「显示/隐藏 变量、列表」把监视器画在 HUD 的状态框里，跟随「HUD 位置」设置；
> 列表最多显示几项可在模组设置里调（默认 5）。
>
> 「当[计时器] > [N]」的「响度」选项在游戏内没有音源，恒不成立；请用「计时器」。

## 四、不支持的积木

- **运动 / 造型 / 背景 / 声音 / 画笔**：Scratch 是 480×360 的 2D 舞台，模组是 3D 世界
  且服务器权威，强行映射会得到「看着像、落点全错」的行为。
- **克隆**：语义与 Minecraft 不对应，并发请用多个帽子积木。

自定义积木（`定义 xxx`）**可以导入并查看**，但游戏内不能修改。

## 五、导出与导入

1. TurboWarp 菜单 **File → Save to your computer**，得到 `.sb3`
2. 把 `.sb3` 放进 `config/turbomc/imports/`
3. 游戏内按 **F7** → 点「导入」
4. 导入的包会自动成为「当前启用」；只有一个包能处于启用状态
5. 点圆点可切换启用，点「展开」可看到包内的每个脚本，「收起」恢复
6. 按 **F6** 启停引擎

导入时按「帽子积木」拆分脚本，命名为 `角色名` 或 `角色名-N`。同一角色下的多个脚本
共享该角色的局部变量，这与 Scratch 的语义一致。

## 六、注意事项

- **浏览器里看不到效果**：扩展积木在 TurboWarp 里只是空实现，真正的验证要在游戏里跑。
- **不要改扩展积木的 opcode**：模组按 `turbomc_<opcode>` 做映射，改名会导致积木失效。
- **变量名、列表名**按名称对应，中文可用。
- **扩展必须先加载再拼积木**，否则导出的项目里没有扩展积木。
- **导入的工程是只读的**：要改脚本请回 TurboWarp 改完重新导出、重新导入。
