# 问题想法库

> 用途：**未完成工作的索引**。一行一件事，只写「是什么、卡在哪、去哪看」。
> 细节不写在这里——展开写在 `OPEN_*.md`（未决问题）或 `ARCHITECTURE.md`（已确认的约束）。
> 最后核对：2026-11-22。

## 使用规则

1. **一行一件事**，摘要不超过一句；需要展开时链到 `OPEN_*.md` 或 `ARCHITECTURE.md` 的章节。
2. **状态只有四种**：`待决策`（要你拍板）、`待实施`（方案已定，缺代码）、`待验证`（代码已就绪，缺真机/复测）、`待确认`（现状不明，先查清）。
3. **关闭即删行**：改了代码 → 先确认 `ARCHITECTURE.md` 已同步，再删该行；决定不做 → 移进文末「已失效」并写一句原因（避免以后再被翻出来重新论证）。
4. **不写时间估算**。估算会失真，也会诱导按估算而不是按收益排序。
5. 与 `OPEN_*.md` 的分工：`OPEN_*` 是**单个问题的详细事实记录**，本文件只是**索引与状态**，不复制其内容。
