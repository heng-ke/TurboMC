## 一、为什么不在 tick 里写视角

原版 `ClientPlayerEntity.getYaw(float)` 在非骑乘时直接返回原始 yaw，相机不做 tick 内插值。
tick 里每 50 ms 写一次就是每 3 帧（60 fps）跳一格的台阶。解法不是「插值」，而是让**写入频率
等于读取频率**：帧回调里按 `1 - exp(-k·dt)` 收敛并限速 240°/s，整条路径不需要 mixin。

选型依据（参考实现的逐项实测、字段与伪代码、分批计划）已随实现落进代码与 `ARCHITECTURE.md` §13；
需要回溯原文看 `git log -- docs/OPEN_VIEW_SMOOTHING.md`。

## 二、待验收清单

**VIEW-01 基础平滑**

1. 直线长距离走向：视角完全静止；
2. 90° 拐角：连续转动，无「3 帧一跳」；
3. 180° 回头：站定转向连续，不来回摆；
4. 走向中动鼠标：立刻跟手，松手后恢复自动；
5. 引擎停止 / 断开连接：视角不再自动转。
